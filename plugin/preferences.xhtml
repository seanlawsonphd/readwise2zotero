Imports Readwise Reader documents that have highlights into Zotero, with highlights attached as a formatted note. Get your access token at readwise.io/access_token. Run a sync anytime from Tools → Sync from Readwise. "Full Rescan" re-examines every highlight in your Readwise library instead of only those changed since the last sync. When Zotero's site translators can't extract metadata from a page, the plugin can send the page text to an AI model for extraction. Pick a provider and fill in its key (or local server details) — the other providers' settings are kept but unused. Anthropic OpenAI Google Gemini Ollama
